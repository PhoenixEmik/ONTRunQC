# Export fonts

Unmodified Liberation Sans Regular and Bold, version 2.1.5, from the
[official Liberation Fonts release](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5).
These Arial-metric-compatible fonts are embedded only with `static-figures`,
so exports need neither system fonts nor network access. SVG/HTML remain unchanged.
